# Стек: .NET 10 / ASP.NET Core / Blazor Web App

Для сервиса бронирования выбран .NET 10: Blazor Web App (Interactive Server) — UI и серверная логика в одном приложении, отдельного SPA-фронтенда нет. Тесты — xUnit + Microsoft.AspNetCore.Mvc.Testing. Зафиксировано, чтобы для небольшого приложения не вводить второй фронтенд-стек.
