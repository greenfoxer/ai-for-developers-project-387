# Хранение: SQLite + EF Core без миграций

Данные хранятся в SQLite через EF Core; схема создаётся `EnsureCreated` без миграций, в Docker-образе БД эфемерна (пересоздаётся с сид-данными при каждом старте). Это осознанное упрощение для демо-проекта: персистентность после перезапуска не является условием приёмки.
