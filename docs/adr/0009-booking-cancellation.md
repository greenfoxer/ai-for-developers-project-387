# Отмена записи: освобождение слота без удаления

Владелец отменяет запланированную запись с панели владельца: освобождённый слот снова доступен для записи, запись не удаляется, а остаётся видимой в списке «Отменённые события». У записи два состояния — запланирована (слот занят, см. ADR-0007) и отменена (слот свободен); жёсткое удаление не используется, чтобы сохранить историю бронирований. Реализовано в PR #14 по issue #13.
