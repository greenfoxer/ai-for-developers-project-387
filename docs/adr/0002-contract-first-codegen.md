# Контракт-первый пайплайн генерации

API описывается в TypeSpec (`contracts/`), из него генерируются OpenAPI 3.0, клиентский SDK (Kiota, C#) и серверные partial-контроллеры (NSwag). Одна команда `scripts/generate.sh` пересобирает всю цепочку идемпотентно. Причина — единый источник истины по контракту и отсутствие ручной синхронизации DTO и маршрутов.
