# Занятость: полуоткрытые интервалы и запрет пересечения

Слот занимает интервал `[start, start + длительность)`. Пересечение интервалов на минуту и более запрещено, в том числе между разными типами событий; следующая встреча может начинаться в момент окончания предыдущей (стык в стык). Проверка выполняется в транзакции записи, проигравший в гонке получает 409.
