# Сетка стартов слотов: фиксированный шаг 30 минут

Сетка стартов — фиксированный шаг 30 минут, якорь 09:00; длительность слота равна длительности типа события и на шаг не влияет.

Status: accepted. Пересматривает прежнее решение «шаг = длительность типа» (issue #10 и предыдущий код `EventTypesImplementation`).

## Considered Options

- **(а) фиксированная 30-минутная сетка** — выбрано: предсказуемый календарь и простой контракт.
- **(б) любая минута рабочего дня** — отвергнуто: слишком плотная сетка для UX.
- **(в) шаг = длительность типа** — отвергнуто: 60-минутный тип прятал бы 30-минутные старты и расходился с требованием.

## Consequences

Для типа длительностью 60 минут старты идут каждые 30 минут, но слот занимает 60; проверка «старт + длительность ≤ 18:00» остаётся.
