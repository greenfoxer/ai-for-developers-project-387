# Время в контракте — wall-clock Europe/Moscow

Контракт оперирует строками «2026-10-21T14:30» без offset, зона — Europe/Moscow (UTC+3 без DST), зафиксирована описанием сервиса. Хранилище использует UTC, конверсия — только в `MskClock` на границе контракта. Отклонение от «правильного» UTC-в-контракте намеренное: минуты и рабочие часы проще читать в локальной зоне владельца.
